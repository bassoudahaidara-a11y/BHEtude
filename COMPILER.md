# BH Étude : compiler l'APK
1. Crée un dépôt GitHub (ex. BHEtude) et envoie-y tout le contenu de ce dossier (.github compris).
2. Actions > Build APK > Run workflow.
3. Télécharge l'artefact « BH-Etude-APK » (app-debug.apk) et installe-le.
Au premier lancement : colle ta clé Groq (console.groq.com/keys).
